# Googleスプレッドシート連携：第2段階（公開案件のみ）

## 方針
- 当面は個人利用。Googleスプレッドシートを**非公開**で管理する。
- GitHub Pagesとこの公開リポジトリに載せるのは、**自治体・官公庁の公開情報だけ**。
- 社内の月次営業PDF、営業担当者、訪問履歴、メモ、対応状況は公開リポジトリ・Gemini無料API・公開Webサイトに保存・送信しない。
- 社内PDFとの重複照合は未実装。許可された社内環境でのローカル照合として別途設計する。

## 1. シートのタブ案
1. **案件マスター（公開情報）**：公開案件ID・案件名・場所・発注者・設計事務所・事業段階・公表日・価格・公式PDF URL・原典URL・確認状態。
2. **AI解析（公開資料のみ）**：案件ID・根拠PDF・解析日時・技術要点・PC適用可能性（推定）・要確認事項。推定は事実と分離する。
3. **収集ログ**：収集元・実行日時・成功・失敗・追加件数・エラー。
4. **営業管理（社内専用、将来）**：会社の承認と適切なアクセス制御が整うまで**作成・同期しない**。

## 2. 公開データをCSVで書き出す
```bash
python scripts/export_public_sheet.py --output /tmp/pc_radar_public.csv
```
Googleスプレッドシートの「ファイル → インポート → アップロード」からCSVを読み込める。
このスクリプトは `official_documents.json` と `data.json` だけを読み、社内PDFは一切読み込まない。
ニュース由来の候補は「未検証」と明記し、公式案件と区別する。
同じ案件IDの二重行は作らないが、異なるIDの同一案件を完全に検知する機能は**まだない**。

## 3. 自動同期に必要な次の設定
現在、Googleスプレッドシートへの編集権限はGitHub Actionsに付与されていないため、**自動同期は未接続**。
Google CloudのSheets APIを利用する場合は、専用サービスアカウントまたはOAuth認証を設定し、
編集権限を対象スプレッドシートのみに限定する。認証情報はGitHub Secretsで扱い、
公開コードやログに記録しない。シートIDはユーザー提供のものを設定に使用する。
API接続・更新競合防止・差分同期のテストが完了するまで自動書き込みは開始しない。

## 4. 確認基準
- 1行＝1案件ID
- 未確認項目は空欄
- 設計事務所・価格・PC採用を推測で埋めない
- URLは公開HTTPSのものだけを出力
- CSV数式インジェクション対策を適用
- 公開データと社内営業データを混ぜない
