# PC案件レーダー

公開されている自治体・官公庁の建築・設計・入札情報を探すモバイル対応Webサイトです。

- 検索条件: 担当者、設計事務所、場所（公開資料に社内担当者は含まれません）
- 公開PDFが存在する場合は原典へのリンクを表示
- 会社の営業PDF・メモ・担当者台帳はアップロードしません
- 更新情報は情報源により未確認・誤検出があり得るため、必ず公表元でご確認ください

Webサイトを利用するには GitHub の **Settings > Pages** で Source を **GitHub Actions** にする必要があります。

社内月次PDFとの重複除外は未接続であり、公開サイトに社内PDFや照合キーを置かない方針です。
